# Mobile design references

Capture reference analysis here after the user supplies the iOS images. Reference images are inspiration, not specifications to reproduce.

For each screen or flow, record:

- The developer task and the corresponding MonoCode desktop behavior.
- Useful interaction and visual principles from the references.
- The proposed mobile adaptation and why it fits MonoCode.
- Loading, empty, error, offline, keyboard, and accessibility considerations.
- Decisions made with the user and any unresolved questions.

Keep reference material separate from app assets. Do not bundle reference screenshots into the application.
